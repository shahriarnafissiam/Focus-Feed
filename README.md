# Muraqabah (Chrome / Brave Extension)

## How to download : 
1. Open the repository Muraqabah .
2. Go to code option on the right corner .
3. Select download zip file and download the folder named - Focus feed main.zip.
4. Then follow the instruction how to load it into your browser .

## How to load it into your browser:

1. Extract the ZIP file to access the `focus-feed` folder.
2. Type `chrome://extensions` or `brave://extensions` into your browser's address bar and press Enter.
3. Enable **Developer mode** (located in the top-right corner).
4. Click the **Load unpacked** button and select the extracted `focus-feed` folder.


## Features (v7.0):
- **Reels Block:** Hides Reels by default. 
- **Clean Feed Mode:** Option to keep the home feed completely empty.
- **Hide Stories:** Option to show or hide the Stories section at the top.
- **Focus Mode (Locked):** Locks all settings for a selected duration—`25m`, `30m`, `60m`, `2hr`, `3hr`, or any **Custom Time** of your choice.

## Who Needs This Extension?

This extension is built for people who are looking for a way to open Facebook simply to stay updated without getting pulled into endless scrolling. Many people enter Facebook just to check updates or specific pages, yet the moment they look at the home feed, they end up stuck in endless scrolling. To protect them from endless scrolling, this extension removes the home feed distraction so they can simply use the search box, search for the page they need, view its content, and stay free from endless scrolling.

১. 'Focus feed' রিপোজিটরিটি খুলুন।

## কীভাবে ব্রাউজারে লোড করবেন:

3. ডান পাশের উপরে থাকা **Developer mode** অন করুন ।।
4. **Load unpacked** বাটনে ক্লিক করে এক্সট্র্যাক্ট করা `focus-feed` ফোল্ডারটি সিলেক্ট করুন।
