# Focus Feed (Chrome / Brave Extension)

## How to load it into your browser:

1. Download and extract the ZIP file to access the `focus-feed` folder.
2. Type `chrome://extensions` or `brave://extensions` into your browser's address bar and press Enter.
3. Enable **Developer mode** (located in the top-right corner).
4. Click the **Load unpacked** button and select the extracted `focus-feed` folder.

## Features (v7.0):
- **Reels Block:** Hides Reels links/tabs.
- **Clean Feed Mode:** Keeps the home feed completely empty.
- **Hide Stories:** Option to show or hide the Stories section at the top.
- **Focus Mode (Locked):** Locks all settings for a selected duration—`25m`, `30m`, `60m`, `2hr`, `3hr`, or any **Custom Time** of your choice.




# Focus Feed (Chrome / Brave Extension)

## কীভাবে ব্রাউজারে লোড করবেন:

1. ZIP ফাইলটি ডাউনলোড করে এক্সট্র্যাক্ট করুন এবং `focus-feed` ফোল্ডারটি বের করুন ।
2. ব্রাউজারের অ্যাড্রেস বারে `chrome://extensions` অথবা `brave://extensions` লিখে এন্টার দিন ।
3. ডান পাশের উপরে থাকা **Developer mode** অন করুন ।।
4. **Load unpacked** বাটনে ক্লিক করে এক্সট্র্যাক্ট করা `focus-feed` ফোল্ডারটি সিলেক্ট করুন।

## ফিচারসমূহ (v7.0):
- **Reels ব্লক:** Reels লিংক/ট্যাব হাইড করে 
- **Clean Feed Mode:** হোম ফিড পুরোপুরি ফাঁকা রাখে 
- **Hide Stories:** উপরের Stories সেকশন অন বা অফ করার সুবিধা।
- **Focus Mode (Locked):** `25m`, `30m`, `60m`, `2hr`, `3hr` অথবা যেকোনো **Custom Time** চলাকালীন সব সেটিংস লক রাখে।
