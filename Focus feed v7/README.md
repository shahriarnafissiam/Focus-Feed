# Focus Feed (Chrome / Brave Extension)

## কীভাবে ব্রাউজারে লোড করবে:
1. ZIP ফাইলটি এক্সট্র্যাক্ট করে `focus-feed` ফোল্ডারটি বের করো।
2. ব্রাউজারের অ্যাড্রেস বারে `chrome://extensions` অথবা `brave://extensions` লিখে এন্টার দাও।
3. ডান পাশের উপরে থাকা **Developer mode** অন করো।
4. **Load unpacked** বাটনে ক্লিক করে এক্সট্র্যাক্ট করা `focus-feed` ফোল্ডারটি সিলেক্ট করো।

## ফিচারসমূহ (v2.0):
- **Reels ব্লক:** Reels লিংক/ট্যাব হাইড করে এবং সরাসরি `/reel` URL-এ গেলে হোমপেজে রিডাইরেক্ট করে।
- **Clean Feed Mode:** হোম ফিড পুরোপুরি ফাঁকা রাখে (Message, Notification, Search স্বাভাবিক থাকে)।
- **Hide Stories:** উপরের Stories সেকশন অন বা অফ করার সুবিধা।
- **Focus Mode (Locked):** `25m`, `30m`, `60m`, `2hr`, `3hr` অথবা যেকোনো **Custom Time** চলাকালীন সব সেটিংস লক রাখে।
